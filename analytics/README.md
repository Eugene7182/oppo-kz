# Analytics Data Mart Layer

## Назначение
Каталог `analytics/` содержит DDL/DML-скрипты витринного слоя для PostgreSQL.
Цель — обеспечить аналитические витрины с соблюдением правил полных периодов и расчётами LFL.

## Порядок деплоя
1. `00_create_schema.sql`
2. Таблицы измерений (`dims/*.sql` в лексикографическом порядке)
3. Таблицы фактов (`facts/*.sql` в лексикографическом порядке)
4. Материализованные представления и view (`views/*.sql` в порядке нумерации)
5. Скрипты обновления (`refresh/*.sql`)
6. Минимальные тестовые вставки (`tests/01_smoke_inserts.sql`)

> **Важно:** выполнять `REFRESH MATERIALIZED VIEW CONCURRENTLY` только после первичной загрузки таблиц и наличия необходимых индексов.

## Нотация и соглашения
- Все объекты создаются в схеме `analytics`.
- Денежные величины — `numeric(18,2)`, количество — `numeric(18,3)`.
- `period_ym` хранится как дата первого дня месяца.
- Флаг LFL (like-for-like) определяется по активным магазинам в обеих сравниваемых периодах.

## Обновление витрин
- `refresh/30_refresh_plan.sql` — рекомендации по плану обновлений (ночное/часовое окна).
- `refresh/31_refresh_functions.sql` — функции и процедуры обновления витрин.

## Тестирование
- `tests/01_smoke_inserts.sql` — минимальный набор данных для smoke-проверки агрегаций и расчётов.
